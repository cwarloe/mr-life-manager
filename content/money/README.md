## Guiding ideas

- **The buffer converts a category of crisis into a category of inconvenience.**
  Everything else in money gets easier once it exists.
- **Irregular expenses are not surprises.** They're annual. They only feel like
  emergencies because nobody set aside monthly.
- **Autopay is delegation to a system that never forgets.**
  ([do-it-now.md](../../frameworks/do-it-now.md))
- **Undesignated money is available money, and available money disappears.**
  Give every dollar a destination.
  ([everything-has-a-place.md](../../frameworks/everything-has-a-place.md) §5)
- **The "stupid tax" is real and nameable:** late fees, overdrafts, replacing
  things you own but can't find, express shipping, convenience premiums.

## Scope boundary

We teach **systems and mechanics** — how accounts work, how to set up autopay,
what a deductible is, what cadence to review on. We do **not** give investment,
tax, or financial advice. This boundary holds absolutely.
