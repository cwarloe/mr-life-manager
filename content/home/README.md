# Home

The physical space you live in — setting it up, keeping it in order, and keeping
it working.

| Subdirectory | Covers |
|---|---|
| [`cleaning/`](cleaning/) | Routines, supplies, standards, cadences |
| [`kitchen/`](kitchen/) | Food, cooking, pantry, kitchen systems |
| [`organization/`](organization/) | Setup, storage, where things live |
| [`hospitality/`](hospitality/) | Hosting, guests, gatherings |

**Also lands here for now:** home maintenance (filters, detectors, appliances,
seasonal tasks). It's a separate domain in
[`life-domains.md`](../../frameworks/life-domains.md) and should get its own
directory once it has enough content to justify one.

**Why Home leads.** It's the visible, urgent, entry-point domain — how people find
us and where trust is earned. It's also where
[preventative-vs-crisis.md](../../frameworks/preventative-vs-crisis.md) is easiest
to demonstrate, because the feedback loop is fast and physical.
