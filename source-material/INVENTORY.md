## How to retrieve them

The Gmail connector exposes attachment *metadata* (filename, type, id) but has no
attachment-download action, so the bytes can't be pulled directly. Two working
paths:

1. **Save to Drive** (preferred). In Gmail, open each thread above and use the
   attachment's "Add to Drive" button. Drive's connector extracts document text
   directly, so nothing has to be re-encoded or retyped.
2. **Convert to Google Doc.** Same thing, but opens the .docx in Docs first —
   useful if the 2009-era formatting matters.

Once any of these lands in Drive, the verbatim-source rule in this folder still
applies: transcribe exactly, put interpretation in a separate analysis file.
