## How to retrieve an attachment

The Gmail connector exposes attachment *metadata* (filename, type, id) but has no
download action, so the bytes can't be pulled from Gmail directly. The working
path, used for all four 2009–2010 guides:

1. In Gmail, open the thread and use the attachment's **"Add to Drive"** button.
2. Drive's connector extracts the document text server-side — nothing has to be
   re-encoded or retyped.

Renaming the file in Drive is fine; these were found by parent folder and
creation date, which Drive preserves from the original attachment.

Whatever arrives, the verbatim-source rule in this folder still applies:
transcribe exactly, put interpretation in a separate analysis file.
