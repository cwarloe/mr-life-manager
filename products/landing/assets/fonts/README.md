Site fonts, self-hosted so no visitor's browser contacts Google: Archivo (`archivo.woff2`, variable weight 400–800) and Source Serif 4 (`source-serif-4.woff2`, roman, variable weight 400–600 with optical sizes; `source-serif-4-italic.woff2`, italic 400). Latin subsets in WOFF2, downloaded 2026-11-12 from the Google Fonts CSS API (request `css2?family=Archivo:wght@400..800&family=Source+Serif+4:ital,opsz,wght@0,8..60,400..600;1,8..60,400`, Archivo v25, Source Serif 4 v15). The `@font-face` rules and the `--font-ui` / `--font-text` tokens are in `assets/tokens.css`. PDFs don't use these files: `render_pdf.py` embeds `products/print/fonts/embedded-fonts.css` instead.

Display fonts for the design-options preview (`/preview/design.html`) and the audience looks: Bangers (Comic Panel theme) and Saira Stencil One (Mission Board theme). Latin subsets in WOFF2, from github.com/google/fonts. The `/students` and `/military` audience pages, and checklists opened from them, use them through `assets/looks.css`; the `@font-face` rules and the `--font-display` token are in `assets/tokens.css`.
